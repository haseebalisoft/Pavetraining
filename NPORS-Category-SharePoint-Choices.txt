Instructions for SharePoint Site Owner:
1. Open the NPORS Register list
2. Settings (gear) → List settings
3. Click column: NPORS Category
4. Under Type each choice on a separate line, DELETE all existing choices
5. Paste the codes between BEGIN and END below (codes only, one per line)
6. Remove junk values such as Choice 8
7. Click OK

Important: store the CODE only (e.g. N001), not the full course title.
